# NevelskyiArt Arkanoid

Космічна гра для Android з героїнею-пілотом.

- **Корабель** унизу стріляє **зеленим бластером**: тримай палець — вогонь, веди пальцем — політ.
- **Астероїди** замість блоків: обертаються, тріскаються, великі потребують кількох влучань, броньовані — шести. Стрій повільно насувається на корабель, а згори падають метеори.
- **Світло зірки:** астероїди й корабель освітлені збоку зіркою рівня (світлий край, тінь з протилежного боку).
- **4 сектори:** Пояс астероїдів → Метеорний дощ → Крижані комети → Вогняна зірка.
- **Бонуси:** `x3` потрійний бластер, `R` швидкий вогонь, `S` щит, `+1` життя.
- **Героїня-пілот** на панелі зліва радіє серіям влучань, лякається при ударі й святкує зачищений сектор.
- На ПК: стрілки — політ, пробіл — вогонь.

## Як отримати APK
Кожен пуш автоматично збирає APK у GitHub Actions:
1. Відкрий вкладку **Releases** у репозиторії (або **Actions → Build Android APK → Artifacts**).
2. Завантаж `NevelskyiArt-Arkanoid.apk` на телефон і встанови його (дозволь встановлення з невідомих джерел).

## Розробка
```bash
npm install
npm run dev            # гра в браузері
npm run android:sync   # зібрати й синхронізувати з Android-проєктом
npx cap open android   # відкрити в Android Studio
```

## Godot 4 версія
Та сама гра на Godot 4.3 (GDScript) лежить у папці `godot/`.
- Відкрий `godot/project.godot` у Godot 4.3+ і натисни ▶.
- APK автоматично збирає workflow **Build Godot Android APK**: файл `NevelskyiArt-Arkanoid-Godot.apk` з'являється в Releases та Artifacts.
- Скрипти: `scripts/main.gd` (гра), `scripts/heroine.gd` (героїня), `scripts/themes.gd` (рівні), `scripts/sfx.gd` (звуки), `scripts/particles.gd` (ефекти).
- Смоук-тест з автопілотом і скріншотами: `godot --path godot res://tests/autotest.tscn -- <папка>`.

## Свої арти
Героїня намальована кодом у `src/heroine.js` (Phaser) і `godot/scripts/heroine.gd` (Godot). Щоб замінити її власними спрайтами, збережи публічні методи `setTheme`, `cheer`, `sad`, `victory`, `surprised`, `changeOutfit`, `tick`. Теми й розкладки рівнів лежать у `src/themes.js`.

# Lingua Rangers (папка `rangers/`)

Гра для вивчення мов: ти рейнджер, що літає зоряною системою, спілкується з мешканцями планет і екіпажами кораблів.

- **Мови:** англійська та іспанська; підказки й меню — українською або російською.
- **4 планети-теми:** Космопорт (знайомство), Ринок Оріона (покупки й числа), Ремонтна станція (корабель і прохання), Медпункт Веги (здоров'я).
- **Діалоги:** мешканець говорить фразу (озвучка голосом пристрою), ти обираєш правильну відповідь. Помилка — пояснення, а фраза повертається в кінці місії.
- **Зустрічі в дорозі:** торговець, корабель у біді, пірати.
- **Прогрес:** кредити, зірки за планети, апгрейди в ангарі (Перекладач, Щит, Двигун), журнал вивчених фраз з озвучкою. Усе зберігається на пристрої.
- **Додати мову:** у `rangers/scripts/content.gd` додай ключ мови (наприклад `"de"`) до кожної фрази й до `TARGET_LANGS`.
- **Збірка:** workflow **Build Lingua Rangers** робить APK (Releases) і веб-версію в гілці `gh-pages` (`/rangers/`).
- **Тест:** `godot --path rangers res://tests/autotest.tscn -- <папка для скріншотів>`.
